## 🌟 Key Highlights & Design Decisions

### 1. Ultra-Clean, Scannable "About Me" & Profile (No Walls of Text)
- Instead of long paragraphs, information is divided into **4 scannable visual cards**:
  - **Who I Am:** Identity, background, and location (Dholka, Ahmedabad).
  - **Education Track Record:** B.E. in IT (Current), Diploma in IT (8.62 CGPA), SSC (72.83%).
  - **What I Specialize In:** Python, Java, JavaScript, Relational Databases, and REST APIs.
  - **Professional Strengths:** Algorithmic debugging, fast execution (75+ WPM), and fluent multilingual teamwork (English, Hindi, Gujarati).

### 2. Practical Projects (Easy to Explain in Any Interview)
Every project features a dedicated **"How to Explain This Project"** callout box:
1. **Student Record & Attendance Management System**
   - *One-sentence pitch:* "A relational database web portal designed for colleges to log student attendance, calculate semester attendance percentages, and generate automated grade reports."
   - *Key topics to discuss:* Relational schema design (Students, Courses, Attendance), CRUD operations, and CSV export.
   - *Tech:* Python / Java, MySQL, JavaScript, HTML5/CSS3.
2. **Interactive Algorithm & Sorting Visualizer**
   - *One-sentence pitch:* "An interactive web app that visualizes sorting algorithms (BubbleSort, SelectionSort, QuickSort) step-by-step with animated comparison bars."
   - *Key topics to discuss:* Array indexing, asynchronous delay loops in JS to animate comparisons/swaps, and time complexity comparisons.
   - *Tech:* JavaScript (ES6+), HTML5 Canvas, CSS Grid.
3. **CampusHub: IT Student Study Resource Portal**
   - *One-sentence pitch:* "A centralized study platform for IT diploma and engineering students to search notes, lab manuals, and exam papers by semester."
   - *Key topics to discuss:* Search filtering, responsive UI layout, and LocalStorage for bookmarking favorite subjects.
   - *Tech:* HTML5, Modern CSS, JavaScript, LocalStorage API.
4. **ByteHop: 2D Arcade Obstacle Dodger (Playable Game)**
   - *One-sentence pitch:* "A 2D arcade game built in pure HTML5 Canvas and JavaScript featuring realistic jump physics, gravity, and bounding-box collision detection."
   - *Key topics to discuss:* The `requestAnimationFrame` 60 FPS loop, velocity vectors, and obstacle generation.
   - *Tech:* JavaScript, HTML5 Canvas, Web Audio API.

### 3. Cartoonist Tactile Interactivity
- **Interactive Robot Coder Mascot:** An animated mascot in the hero section whose eyes physically track your mouse cursor across the screen! Clicking the bot triggers cheerful smiles, tech quotes, and celebratory confetti.
- **Playable Mini-Game Cabinet:** Visitors can play ByteHop directly on the page using the Spacebar or clicking/tapping to jump.
- **Light & Vibrant Palette:** Built with a crisp `#F8FAFC` background, high-contrast slate typography (`#0F172A`), and tactile 3D drop-shadow buttons.
